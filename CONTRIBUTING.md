# Contributing to CodePilot

This is a learning capstone project, but development follows production-oriented practices.

## Before considering a feature complete

- Implementation is complete and scoped.
- Tests are added/updated.
- README/docs are updated.
- Significant design decisions are recorded.
- Tool substitutions are recorded.
- Significant engineering issues are recorded.
- Secrets are not committed.
- Relevant lint/tests pass.
