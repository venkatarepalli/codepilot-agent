- `skills.md` — Skills
- `memory.md` — memory architecture

- `guardrails.md` — security controls

- `testing.md` — test strategy and commands
- `github-integration.md` — GitHub workflows
- `troubleshooting.md` — user-facing recovery procedures
- `design-decisions.md` — decision index
- `tool-substitutions.md` — assignment tool substitutions
- `requirement-matrix.md` — requirement/test/demo tracker
- `demo-script.md` — final demonstration runbook
- `engineering-issues/` — significant problems and resolutions
- `adr/` — architecture decision records
- `runbooks/` — operational procedures
